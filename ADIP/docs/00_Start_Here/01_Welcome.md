# Welcome to ADIP

**ADIP (Automation Delivery Integration Platform)** is an enterprise AI SDLC
platform: enter one business prompt and it orchestrates the full delivery
lifecycle — requirements, architecture, development, testing, release, go-live,
audit, executive summary, artifact generation and traceability.

- **Frontend:** React 19 + Vite 8 + TypeScript + MUI
- **Backend:** FastAPI + SQLAlchemy + Alembic + Pydantic (SQLite dev / PostgreSQL prod)
- **AI:** provider-independent LLM layer (mock by default; Ollama for real local execution)
