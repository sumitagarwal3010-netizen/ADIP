# 05 — ADIP Artifact Catalog

ADIP generates downloadable executive deliverables across every center.
Every generated artifact is **automatically registered in the Universal
Artifacts Repository** at `/artifacts` where it can be searched, viewed and
downloaded.

## How Artifacts Are Generated

Two complementary generation flows cover every screen:

| Surface | Generator | Stored in | Output |
| --- | --- | --- | --- |
| AI SDLC Copilot tabs | `CopilotSection` (in-page action strip) | Universal Artifacts Repository + per-tab list | Preview-grade DOCX/XLSX (`Download` button on every card) |
| Center "AI Reports" tabs | `HubArtifactGenerator` (full progress flow) | Universal Artifacts Repository + per-tab list | Executive-grade DOCX/XLSX/YAML/PNG with sections, executive summary, risk rating |
| KPI Catalog page | KPI catalog `Generate` button | Universal Artifacts Repository | KPI Catalog Markdown + CSV |

Both flows produce real, downloadable text artifacts (the `Download` action
materializes the artifact body as a blob and triggers a browser download).

## Artifact Metadata

Every artifact carries the following metadata, surfaced in both the in-page
artifact card and the Universal Artifact Repository:

- ID, Name, File Type (DOCX / XLSX / YAML / PNG)
- Generated By (AI agent role)
- Model Used, Version, Generated Date / Timestamp
- Approval Status (Approved / Pending Review / Draft / Rejected)
- Risk Rating (Low / Medium / High / Critical)
- Source Hub & Source Label (which center authored the artifact)
- Executive Summary, Sections (Executive Summary, Key Findings,
  Recommendations, Approval & Sign-off)
- Full preview content
