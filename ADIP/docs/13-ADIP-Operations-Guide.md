# 13 — ADIP Operations Guide

How to run, monitor and operate ADIP in a demo or pre-production
environment.

## Runtime Profile

ADIP is a **front-end-only** SPA in its current demo configuration. There
is no backend server, no database and no external API calls. All data is
generated by `simulationEngine.js` in-browser.

For production operation, follow [`12-ADIP-Developer-Guide.md`](./12-ADIP-Developer-Guide.md)
to wire to real telemetry sources.

## Hosting

### Static hosting (recommended)

After `npm run build`, deploy `dist/` to any static host:

- Vercel / Netlify / Cloudflare Pages
- S3 + CloudFront
- Azure Static Web Apps
- Internal Nginx

Single-page app routing — make sure all paths fall back to `index.html`.

### Reverse proxy / SPA fallback

For Nginx:

```
location / {
  try_files $uri $uri/ /index.html;
}
```

## Health Checks

For demo: load `/` and verify the Executive Control Tower renders within
3 seconds.

For production wiring: instrument the simulation engine replacement to
emit health metrics from the data fetcher (Datadog / Prometheus / OpenSearch).

## Performance

- Build target: ES2022.
- Minified bundle: ~2.4MB (~610KB gzipped) — acceptable for an internal
  executive tool. For broader rollout, code-split the centers using
  `React.lazy`.
- Simulation tick: 30 seconds; one tick costs ~1ms in the browser.

## Observability

Browser-side logging only in this demo. To capture telemetry:

1. Add a top-level `<ErrorBoundary>` reporter (already there:
   `RootErrorBoundary`) that posts to your error sink.
2. Add a route-change tracker that records page views.
3. Add a Generate-action tracker to count artifact generation events.

## Backup & Recovery

The artifact registry is in-memory and session-scoped. Closing the tab
clears all artifacts. For persistent storage:

- Wire `ArtifactsContext` to `localStorage` (single-user) or to an
  enterprise document store (multi-user).
- The `Artifact` shape (`src/types/artifacts.ts`) is the canonical
  serialization format.

## Security

- All data is in-browser. No PII is loaded from external systems in the
  demo build.
- Authentication is simulated through a persona switcher (no real auth).
  Replace `AuthenticationProvider` with your enterprise SSO integration
  for production.
- RBAC is enforced via `rbacCatalog.ts`. Routes return 403 for
  unauthorized personas.

## Incident Response (Operational Runbook)

1. **Page won't load** — check browser console; clear cache; check the
   build hash matches the hosted bundle.
2. **Generate button stalls** — open DevTools; verify
   `useGenerationSimulation` is firing the timers.
3. **Artifact list is empty in `/artifacts`** — confirm the `ArtifactsProvider`
   wraps the BrowserRouter (in `App.tsx`).

## Maintenance

- Re-run `npm run build` after every dependency update; commit the hash.
- Keep `KPI_CATALOG` and `hubArtifactDefinitions` in sync with the
  on-screen surfaces.
- Reflect any tab/route additions in `navConfig`, `rbacCatalog` and
  `AppLayout.pageMeta`.
